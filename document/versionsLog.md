## 版本 1.2.0 - 自走棋模式系统 (2025-07-16)

### 🎯 核心新功能

#### ♟️ 完整自走棋游戏系统
- **新增** `AutoChessMode` 核心类 - 完整自走棋游戏逻辑实现
- **新增** 8人对战支持 - 支持最多8名玩家同时游戏
- **新增** 回合制游戏流程 - 30秒准备阶段 + 45秒战斗阶段 + 自动结算
- **新增** 棋子购买系统 - 5个稀有度等级，智能棋子池管理
- **新增** 经济系统 - 金币、利息(每10金币1利息，最多5)、连胜/连败奖励
- **新增** 商店机制 - 基于等级的概率刷新，实时库存同步
- **新增** 备战席管理 - 8个棋子存储位置，支持拖拽放置

#### 🎮 自走棋UI界面系统  
- **新增** `autochess-panel` React组件 - 完整自走棋控制界面
- **新增** 游戏状态监控 - 实时显示回合、阶段、剩余时间
- **新增** 玩家信息面板 - 生命值、金币、等级、经验、连胜状态
- **新增** 棋子商店界面 - 5个商店位置，稀有度颜色标识
- **新增** 备战席可视化 - 8个备战席位，棋子信息展示
- **新增** 游戏控制按钮 - 开始游戏、结束游戏、投降操作
- **新增** 调试控制面板 - 开发模式下的调试功能

#### 🎯 棋子数据系统
- **新增** 棋子数据库 - 完整的棋子属性定义系统
- **新增** 稀有度系统 - 普通(白)、不常见(绿)、稀有(蓝)、史诗(紫)、传奇(橙)

- **新增** 初始棋子库 - 敌法师、水晶室女等基础棋子

#### 🛠️ 自走棋调试命令扩展
- **新增** 自走棋模式命令：`-autochess <action>` - 模式激活、游戏控制

### 🎮 游戏特性

#### 经济系统设计
```
总收入 = 基础收入(5) + 利息收入 + 连胜/连败奖励

利息收入 = min(floor(当前金币/10), 5)
连胜奖励 = min(连胜数, 3) (连胜≥2时)
连败奖励 = min(连败数, 3) (连败≥2时)
```

#### 棋子稀有度概率
| 稀有度 | 等级1 | 等级2 | 等级3 | 等级4 | 等级5+ |
|--------|-------|-------|-------|-------|--------|
| 普通(1费) | 100% | 70% | 60% | 50% | 40% |
| 不常见(2费) | 0% | 30% | 35% | 35% | 35% |
| 稀有(3费) | 0% | 0% | 5% | 10% | 20% |
| 史诗(4费) | 0% | 0% | 0% | 4% | 4% |
| 传奇(5费) | 0% | 0% | 0% | 1% | 1% |

## 🚀 快速开始

### 启动练功房模式
```bash
# 启动开发环境（自动进入训练模式）
npm run launch:tools

# 或者游戏内手动切换
-mode training
```

### 启动自走棋模式  
```bash
# 启动项目并手动激活自走棋模式
yarn dev

# 游戏内激活自走棋模式
-autochess activate
-autochess game start

# 或者自动检测模式启动
yarn launch autochess_map
```

### 常用命令
```bash
# 通用命令
-help                    # 查看所有命令
-mode                    # 查看/切换游戏模式

# 练功房模式命令
-training status         # 查看训练状态
-spawn <unit> [count]    # 生成测试怪物
-scenario start <id>     # 开始测试场景
-refresh                 # 刷新英雄状态

# 自走棋模式命令
-autochess status        # 查看自走棋状态

-shop refresh            # 刷新商店
-chess_info              # 查看棋子信息
```
