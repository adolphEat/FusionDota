# 修复版训练模式命令使用指南

## 🎯 问题修复说明

本次更新修复了CD设置命令无效的问题，并添加了控制台命令支持，提供更简便的使用方式。

### ✅ 修复内容

1. **CD管理API修复**: 改用 `EndCooldown()` + `StartCooldown()` 的可靠方法
2. **控制台命令支持**: 添加全局控制台命令函数
3. **简化聊天命令**: 提供更直观的快捷命令
4. **错误处理优化**: 改进命令反馈和错误提示

## 🚀 新增简化命令

### 聊天命令（游戏内输入）

| 命令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| `-cd <秒数>` | 快速设置CD时间 | `-cd 3` | 设置所有技能CD为3秒 |
| `-regen` | 切换自动回血回蓝 | `-regen` | 开启/关闭自动回血回蓝 |
| `-练功` | 一键开启练功模式 | `-练功` | 开启所有练功功能 |

### 控制台命令（控制台输入）

| 命令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| `training_cd(秒数)` | 设置CD时间 | `training_cd(3)` | 设置CD为3秒 |
| `training_regen()` | 切换自动回血回蓝 | `training_regen()` | 切换状态 |
| `training_practice()` | 一键练功模式 | `training_practice()` | 开启全部功能 |
| `training_status()` | 查看状态 | `training_status()` | 显示所有状态 |

## 📖 详细使用方法

### 1. 快速设置CD时间

**聊天命令方式**：
```bash
# 在游戏聊天中输入
-cd 1      # 设置1秒CD（极速模式）
-cd 3      # 设置3秒CD（默认模式）
-cd 5      # 设置5秒CD（接近真实）
-cd        # 查看当前CD设置
```

**控制台命令方式**：
```bash
# 在控制台输入（按~键打开控制台）
training_cd(1)    # 设置1秒CD
training_cd(3)    # 设置3秒CD
training_cd()     # 查看当前设置
```

### 2. 自动回血回蓝控制

**聊天命令方式**：
```bash
-regen    # 切换自动回血回蓝状态
```

**控制台命令方式**：
```bash
training_regen()    # 切换状态
```

### 3. 一键练功模式

**聊天命令方式**：
```bash
-练功    # 一键开启：自动回血回蓝 + 3秒CD
```

**控制台命令方式**：
```bash
training_practice()    # 一键开启所有练功功能
```

### 4. 查看状态

**控制台命令方式**：
```bash
training_status()    # 显示完整状态信息
```

## 🛠️ 故障排除

### 问题1: CD设置仍然无效
**解决方案**: 
```bash
# 1. 确认训练模式已启动
-training start

# 2. 检查当前状态
training_status()

# 3. 重新设置CD
-cd 3

# 4. 使用技能测试是否生效
```

### 问题2: 控制台命令无法使用
**解决方案**:
```bash
# 1. 确保按~键打开了控制台
# 2. 输入完整的函数调用，包括括号
training_cd(3)    # 正确
training_cd 3     # 错误

# 3. 检查训练模式是否初始化
training_status()
```

### 问题3: 聊天命令输入错误
**解决方案**:
```bash
# 1. 确保在聊天框中输入（按Enter键）
# 2. 命令前必须有 - 符号
-cd 3      # 正确
cd 3       # 错误

# 3. 参数之间用空格分隔
-cd 3      # 正确
-cd3       # 错误
```

## 🔍 技术改进说明

### API修复
- **旧方法**: 直接使用 `StartCooldown()` 可能不生效
- **新方法**: 先 `EndCooldown()` 再 `StartCooldown()` 确保生效

### 命令架构
- **双重支持**: 聊天命令 + 控制台命令
- **向下兼容**: 原有命令仍然可用
- **简化接口**: 新增快捷命令更易用
